# Meridian MUN 2026

A responsive recruitment landing page for a fictional Model United Nations
conference. The experience is built with semantic HTML, modern CSS, and
vanilla JavaScript.

## Highlights

- Editorial, diplomacy-inspired visual design
- Responsive layouts for mobile, tablet, and desktop
- Interactive committee filters and expandable details
- Accessible navigation, focus states, and reduced-motion support
- No build step or framework required

## Run locally

Open `index.html` directly, or serve the folder with:

```sh
python3 -m http.server 4173
```
